## What I Built

An end-to-end **Football Intelligence Hub** powered by Claude and the ABTalks WorldCup Intelligence Master workbook — a multi-stage interactive experience that delivers a World Cup 2026 prediction report, a Football IQ quiz, and a Messi vs Ronaldo personality match, culminating in a personalised Football Intelligence Profile.

## 💡 Key Learnings

### 1. Prompt engineering as experience design
This wasn't a simple Q&A prompt — it was a staged experience with conditional logic. Breaking the prompt into explicit numbered stages (Stage 0 → 1 → 2 → 3 → Final Output) with `sendPrompt()` handoffs between them showed how Claude can be architected like a product, not just queried like a search engine.

### 2. Data grounding changes everything
Every prediction, confidence score, and player insight was traceable to a specific workbook table. Anchoring Claude to a real data source eliminated hallucination risk and made the output defensible. The confidence scores (72%, 63%, 41%) felt earned because they referenced historical win rates and live match results — not guesswork.

### 3. Personality mapping without direct questions works better
Stage 3 never asked "Are you more like Messi or Ronaldo?" It asked about leadership under pressure, reaction to failure, learning style, and legacy. The indirect approach produced a more honest and surprising result — and the user's own astonishment at the output ("I like Ronaldo more but got 58% Messi") was the most engaging moment of the whole experience.

### 4. Claude knows you better than you think
Scoring 80/100 on a football IQ quiz after claiming "basics only" knowledge, then getting correctly identified as a Creative Playmaker despite self-identifying as a Ronaldo fan — both results showed the same thing. Honest behavioural responses reveal more than self-reported labels. Claude picks up on patterns the user doesn't consciously notice.

### 5. Interactive HTML artifacts extend engagement
Building the quiz as an interactive widget (with progress tracking, selected state on buttons, `sendPrompt()` auto-submission) rather than a static text list transformed the experience. Users don't answer quizzes in text boxes — they click buttons. Matching the UI to the task type dramatically improves engagement.

### 6. The "funny surprise" is the shareable moment
The most LinkedIn-worthy outcome wasn't the technical build — it was the irony of a non-football-fan who prefers Ronaldo being told she's 58% Messi. Design experiences where the output surprises the user in a relatable, personal way. That's what gets shared.
